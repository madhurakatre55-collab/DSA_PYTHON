# DSA_PYTHON

My Python practice code for learning and revising data structures and algorithms. These files are my personal reference notes.

## What’s here

- **Arrays:** 1D and 2D arrays, with examples of inserting, updating, deleting, and searching values.
- **Linked lists:** Singly linked lists and a doubly linked list, with basic node and list examples.
- **Stacks:** Basic stack operations like push and pop, plus a small example of converting an infix expression to postfix.
- **Theory notes:** Notes about traversal, including preorder, inorder, and postorder traversal.

The repository is a collection of practice scripts, so some files may be works in progress.
